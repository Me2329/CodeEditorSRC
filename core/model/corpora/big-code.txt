# Each repository is cloned shallow, read once and deleted, so peak disk is the
# growing token stream plus whichever repository is being read. The list is
# ordered largest first: if a token budget cuts the run short, the corpus is
# still broad rather than being whatever sorted first alphabetically.
#
# Weighted towards systems languages because that is what the editor compiles.
